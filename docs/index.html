Anleitung Tandem-Matcher

Schritt-für-Schritt Anleitung

1

Chrome Extension installieren

  1. Gehe zu "Export & Einstellungen"
  2. Klicke auf "Extension herunterladen"
  3. Entpacke die ZIP-Datei
  4. Öffne Chrome → chrome://extensions
  5. Aktiviere "Entwicklermodus" (oben rechts)
  6. Klicke "Entpackte Erweiterung laden"
  7. Wähle den entpackten Ordner aus
2

Profile sammeln

  1. Öffne das SwaF-Portal (portal.startwithafriend.de)
  2. Öffne ein Profil, das du matchen möchtest
  3. Die Extension sammelt das Profil automatisch
  4. Wiederhole für alle Profile, die du matchen möchtest
  5. Klicke auf das Extension-Icon in der Toolbar
  6. Klicke "In Zwischenablage kopieren"
3

Profile importieren

  1. Öffne den Tandem-Matcher
  2. Klicke auf "+ Profile importieren"
  3. Klicke auf "Aus Zwischenablage einfügen"
  4. Prüfe die Vorschau und klicke "Importieren"
4

Tandem matchen

  1. Klicke auf ein Profil in der Liste oder auf der Karte
  2. Das Smart Match Panel zeigt passende Partner
  3. Sterne zeigen die Match-Qualität (mehr = besser)
  4. Klicke auf einen Vorschlag um das Tandem zu erstellen

Tipp: Gelb = Local, Türkis = Newcomer, Grün = bereits vermittelt

5

Gemeinsamkeiten bearbeiten

  1. Im Editor siehst du alle Felder beider Profile
  2. Klicke "KI generieren" für automatische Textvorschläge
  3. Bearbeite die Texte nach Bedarf
  4. Aktiviere/deaktiviere Felder mit dem Schalter links
  5. Klicke "Kopieren" für die Word-kompatible Tabelle
6

E-Mail versenden

  1. Öffne dein E-Mail-Programm
  2. Füge die kopierte Tabelle ein (Strg+V)
  3. Ergänze Anrede und Grußformel
  4. Sende die E-Mail an beide Tandem-Partner
