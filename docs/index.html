Extension herunterladen
Installationsanleitung
  1. Lade den Extension-Ordner herunter
  2. Öffne Chrome und gehe zu chrome://extensions
  3. Aktiviere oben rechts den Entwicklermodus
  4. Klicke auf "Entpackte Erweiterung laden"
  5. Wähle den extension-Ordner aus
  6. Die Extension erscheint jetzt in deiner Toolbar

Tipp: Pinne die Extension für schnellen Zugriff an die Toolbar.

Kurzanleitung Tandem-Matcher

1. Profile sammeln

🧩
Chrome Extension (empfohlen)
Installiere die Extension und sammle Profile direkt vom Portal.
📋
Import
Klicke auf "Profile importieren" und füge JSON-Daten ein.

2. Tandems matchen

🗺️
Karte & Liste
Profile werden auf der Karte und in der Liste angezeigt. Gelb = Local, Türkis = Newcomer.
⭐
Smart Match
Klicke auf ein Profil für automatische Match-Vorschläge. Sterne zeigen die Match-Qualität (1-5).
👆
Manuelles Matchen
Klicke "Manuell matchen" und wähle zwei Profile aus.

3. Tandem bearbeiten

📝
Textvorschlag anpassen
Im Editor kannst du Antworten bearbeiten und Kommentare hinzufügen. Nutze 💡 für Vorschläge oder 🤖 für KI-Unterstützung.
📋
In Word kopieren
Klicke "Kopieren" - die Tabelle wird formatiert in die Zwischenablage kopiert.

4. Verwaltung

✅
Bereits vermittelt
Grüne Profile sind bereits in einem Tandem. Klicke darauf zum Bearbeiten oder Auflösen.
💾
Export
Im Tab "Export & Einstellungen" kannst du Tandems als Excel exportieren und Backups erstellen.

Tipps

  • 📍 Profile werden nach PLZ auf der Karte gruppiert
  • 🔴 Rot markierte Profile sind ausgewählt
  • ⚠️ Bei unpassenden Matches siehst du den Grund
  • 📱 Auf Mobilgeräten: Wechsle zwischen Karte und Liste
